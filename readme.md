# Employee Management System

## Description

A simple Python project used to manage employee details using object-oriented programming concepts.

## Functionality

- Add normal employees
- Add sales employees
- Store employee details such as name, ID, department, and salary
- Store sales targets for sales employees
- Display all employee details
- Demonstrate inheritance using `Employee` and `SalesEmployee` classes

## Basic Usage

1. Run the `main.py` file.
2. Enter the number of employees.
3. Select the employee type.
4. Enter the requested employee details.
5. The program displays the details of all employees.

## Files

- `employee.py` – Contains the employee classes.
- `main.py` – Handles user input and displays employee details.
